## Acceptance Criteria additions (security)

| #   | Criterion                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| --- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | Every explicit native-output attempt targeting filesystem root, checkout root, a checkout descendant, or an ancestor containing the checkout returns nonzero before any mutation; include symlink aliases of overlapping destinations. Verify destination, checkout and neighboring sentinel bytes/inventory remain unchanged. Basis: `docs/plans/codex-native-packages/feature-spec.md:50`; containment precedent: `scripts/package_model.py:185-196`.                                   |
| 2   | Managed-path symlinks are rejected before any write, copy, chmod or prune, covering package roots, existing managed parents and managed file leaves, including dangling symlinks. Linked targets and unrelated sentinels remain unchanged. Basis: `docs/plans/codex-native-packages/feature-spec.md:50`; detailed boundary: `docs/plans/codex-native-packages/research-security.md:85-87`.                                                                                                |
| 3   | Generating and regenerating into a valid external output preserves unrelated neighboring files, including siblings under DEST, `.codex-plugin`, and `.agents/plugins`; removes only stale generator-owned payload according to the declared ownership inventory, including stale MCP under native skills-only ycc; never recursively replaces DEST. Basis: `docs/plans/codex-native-packages/feature-spec.md:46,50`; owned-pruning precedent: `scripts/generate_codex_skills.py:107-127`. |
| 4   | `--native-output DIR --check` reports missing, changed and stale owned output with a nonzero result while leaving existing DIR byte/inventory-identical; checking a nonexistent DIR creates nothing. `--dry-run` creates no files/directories and performs no pruning. Basis: `docs/plans/codex-native-packages/feature-spec.md:50`; check precedent: `scripts/generate_codex_plugin.py:141-154`.                                                                                         |
| 5   | Native `.codex-plugin/ycc-mcp/.mcp.json` parses exactly as `{"mcpServers": build_codex_mcp_config()["mcp_servers"]}` and retains repository Codex overrides. Xero has `env_vars` containing `XERO_CLIENT_ID` and `XERO_CLIENT_SECRET`, not literal `${XERO_*}` env values. Basis: `docs/plans/codex-native-packages/feature-spec.md:46,70`; translator: `scripts/generate_codex_mcp.py:41-61,80-93`.                                                                                      |
| 6   | With conspicuous harmless Xero sentinel values set in the generator process environment, generated files and captured stdout/stderr contain neither sentinel; generated MCP bytes equal output with those variables absent. No credentialed MCP process is launched to prove pass-through. Basis: `docs/plans/codex-native-packages/feature-spec.md:30,86`; `docs/plans/codex-native-packages/research-security.md:113`.                                                                  |
| 7   | Default generation keeps legacy manifest, combined MCP and discovered `local-ycc-plugins` catalog byte-identical; explicit external generation does not modify those checkout files or register/enable packages in user HOME. Basis: `docs/plans/codex-native-packages/feature-spec.md:25-26,50,58-60`; user-marketplace separation: `docs/plans/codex-native-packages/research-security.md:40`.                                                                                          |
