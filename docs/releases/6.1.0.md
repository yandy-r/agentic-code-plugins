# Release 6.1.0 — 2026-10-23

## Summary

ycc 6.1.0 adds native support for OMP (oh-my-pi), with omp 18.12.2 or later. The `ycc`, `ycc-mcp` and `ycc-rules` OMP packages are listed in the root `.omp-plugin/marketplace.json`. `install.sh --target omp` installs, updates, removes and migrates them at user or project scope. The release also adds item selection to `install.sh` (`--skills`, `--agents`, `--commands`, `--plugins`, `--mods`, `--hooks` and `--with-deps`), and fixes for the opencode restricted-agent permissions. A new live CI workflow runs the OMP acceptance harnesses against pinned omp releases on Linux and macOS.

## Upgrade Notes

No breaking changes; existing Claude, Codex, Cursor and opencode installs need no action.

- OMP users: run `omp plugin marketplace add https://github.com/yandy-r/ystack.git`, then `omp plugin install ycc@ycc ycc-mcp@ycc ycc-rules@ycc`. Alternatively, run `install.sh install --target omp`. To upgrade, run a bare `omp plugin upgrade`. omp 18.12.6 upgrades only the first target when given several (upstream can1357/oh-my-pi#16826).
- Native Windows is unsupported for the OMP target; WSL 2 is expected to work but is unverified. See `docs/install/omp.md`.
