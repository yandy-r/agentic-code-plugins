## Upgrade Notes

No action required. Installed plugins do not embed Node.js, and this patch does not change skills, agents, or commands.

Repository checkouts and CI pick up Node.js 22.23.4 for the validate and live OMP workflows, and Node.js 24.22.1 for mise and the release workflow. The dev lockfiles pin markdown-it to 14.3.3. Node.js 20 and other end-of-life lines are outside the October 2026 fixes; use 22.x or 24.x.

Publishing the `v6.1.1` tag is what ships the experimental, opt-in `@yandy-r/ycc-opencode` package. The `install.sh` file copy remains the primary opencode path.
